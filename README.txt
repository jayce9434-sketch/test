ANGRY FLOCK V2.4 — PROJECTILE ENGINE REBUILT

THIS VERSION DOES NOT USE MATTER.JS TO FLY THE ACTIVE BIRD.

That system was causing the top-left / sky launch bug on touch devices.
V2.4 uses deterministic custom projectile movement for the active bird.

- Every pig
- Every wood/glass/stone block
- Falling structures
- Fall damage
- Knockback and collapse

What is custom:
- Active bird flight path
- Bird collision damage
- Bird-to-structure impulse

Also included:
- Live score
- Live 0–3 stars
- Pig/destruction/impact points
- Unused-bird bonus
- Skins
- Music/sound
- Mobile support
- Saving
- Level selection
